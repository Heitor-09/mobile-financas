# 💰 Minhas Finanças - App de Controle Financeiro

Um aplicativo simples, leve e eficiente para controle de despesas pessoais, desenvolvido em **React Native** com **Expo**. 

O projeto foi projetado com arquitetura simplificada em arquivo único (App.js), focado em alta performance, usabilidade intuitiva e persistência de dados local sem dependências desnecessárias.

---

## 🚀 Funcionalidades

**📈 Visualização de Total Gasto**: Cartão em destaque com a soma automatizada de todas as despesas cadastradas.
**➕ Adição de Despesas**: Cadastro rápido informando descrição e valor (suporta decimais e vírgulas).
**🗑️ Remoção de Despesas**: Exclusão individual de itens da lista com atualização instantânea do saldo total.
**💾 Persistência Local**: Todos os dados são salvos localmente no dispositivo via AsyncStorage e mantidos mesmo após fechar o aplicativo.
**🛡️ Validação de Dados**: Impede cadastros com campos vazios ou valores inválidos.

---

## 🛠️ Tecnologias Utilizadas

**[React Native](https://reactnative.dev/)**: Framework para desenvolvimento mobile multiplataforma.
**[Expo](https://expo.dev/)**: Plataforma/ecosistema de desenvolvimento React Native.
**[@react-native-async-storage/async-storage](https://react-native-async-storage.github.io/async-storage/)**: Armazenamento chave-valor assíncrono para persistência local.
